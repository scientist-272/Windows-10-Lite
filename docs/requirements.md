# 💻 Windows 10 Lite — System Requirements

## Minimum Requirements

| Component    | Minimum          |
| ------------ | ---------------- |
| Processor    | 1 GHz 64-bit CPU |
| RAM          | 2 GB             |
| Storage      | 32 GB            |
| Architecture | x64              |
| USB          | 8 GB+            |
| Firmware     | BIOS or UEFI     |

## Recommended

| Component    | Recommended |
| ------------ | ----------- |
| Processor    | 2+ cores    |
| RAM          | 4–8 GB      |
| Storage      | 64 GB+ SSD  |
| Architecture | x64         |
| USB          | 16 GB       |
| Firmware     | UEFI        |

## Important

Actual requirements can vary depending on the particular Windows 10 Lite build.

Before installation:

* Back up important files.
* Verify the ISO checksum.
* Make sure the computer supports x64.
* Make sure you have a valid Windows license.
* Ensure the target disk has enough free space.

## ⚠️ Data Warning

A clean installation may delete files and partitions.

Back up important data before installing.
